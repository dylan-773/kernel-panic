# Ruling 11 - DIVE OPPONENT IDENTITY TAG

*Added 2026-07-29, Loremaster gate on the UI integration cycle.*

[[dive-exe]] labels the opponent **INTRUSION** everywhere: board port tag, the YOU / INTRUSION turn pair, telemetry heading. This replaced the placeholder SIG-0.

It applies on **every** dive, including the opening tutorial and every Sunday attempt against the locked machine later revealed as [[patch]].

**Permitted because** INTRUSION is the world's own diagnostic class for any AI signal occupying a device that is not yours, not a name and not a pronoun. It says no more than the pre-existing threat banner already said on the same dives.

**No mid-dive relabeling on a win.** The name Patch is revealed in the scene that follows the dive, not the dive's own UI, so DIVE.EXE reads INTRUSION straight through the winning dive itself without pre-empting the ending.

**Forbids:** INTRUSION used as a proper name or direct address rather than a diagnostic tag. Also forbids reading this ruling as deciding what the tag says **after** the reveal, which it does not, and which now matters more because play continues afterwards.

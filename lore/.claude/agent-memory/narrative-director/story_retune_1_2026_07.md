Brief `story-retune-1` asked for explicit (no-fallback) openers and enders for runs
1-12, day-open cutscenes for days 1-10, and tutorial-intro/tutorial-outro. Full
proposal is in `pipeline/proposals/narrative-director.json`. Key decisions to
carry forward:

**Sector echo mapping for enders 9-12 (holds until the sector 8/9 conflict below
is resolved).** The brief wanted the sector sequence to continue toward sector 9
by run 10, but ledger Resolved ruling 3 (2026-07-25) hard-forbids sectors 8 and 9
ever appearing as numbered fragments outside the finale. I resolved this by
having enders 9-12 replay already-unlocked sectors verbatim, framed with the
ledger's own "SECTOR SCAN: NO NEW DATA. ECHO FOLLOWS." convention: run 9 echoes
sector 1 (solder lesson), run 10 echoes sector 6 (one more game), run 11 echoes
sector 4 (keep the door shut), run 12 echoes sector 2 (the shop and I have some
talking to do). If a future cycle asks for runs 13+, continue rotating through
sectors 1-7 rather than reusing 9, 10, 11, 12's exact picks back to back, and
never introduce sector 8 or 9 as a numbered fragment without an explicit new
ruling overriding Resolved ruling 3.

**Day-open scenes (days 1-10) are deliberately run-count-agnostic.** They play
identically on every run's day N regardless of run number, so they must never
carry Rhea's evolving virus-theory belief (that belief is run-gated, and the
same day-open-3 plays for a run-1 player and a run-11 player). Keep day-opens in
the "daily shop rhythm" register only: till, spike, ledger, customer devices,
Rhea's logistics voice, and bare physical (not theory-laden) facts about the
back room. Day 10 is the one brief-mandated exception ("replaces the
finale-door copy") but even it stays neutral, using only the already-established
phrase "the back room settles up" rather than asserting a belief. This is a
structural rule, not a one-off choice: if a future brief asks for day-opens to
vary by run, that is new scope requiring a design conversation, not something to
improvise.

**Rhea's post-run-8 arc (openers 9-12) is emotional, not factual.** The ledger
says knowledge plateaus at the run-8 state until the finale win. I built four
runs of visible softening (9: first tender gesture toward the door, 10:
struggling with "it" no longer feeling right, 11: fear gone, 12: open
anticipation) using zero new ground-truth claims, only callbacks to her own
already-shipped lines. This is the template for any further "make Rhea's arc
progress without breaking the plateau" asks.

**Openers 2-6 got a second sister beat inserted (not a rewrite).** Brief wanted
"at least two sister beats per opener" for all 12 runs; runs 1-6 originally had
only one each (except run 1, which already had two). I added a short new sister
beat before the existing one in each, sourced only from the immediately
preceding run's own ender reveal (e.g. opener 5's new beat riffs on ender 4's
"it paces you" line). Existing beats were kept 100% verbatim per the "extend,
do not churn" instruction.

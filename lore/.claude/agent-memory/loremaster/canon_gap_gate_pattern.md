When a gated proposal rests on a world fact the bible/ledger never ruled on
(not a contradiction, an absence), the fix is not APPROVE-by-default or a
REVISE with no citation. Decide the gap, write ONE new ruling into
`lore/ledger.md`'s Resolved rulings list (append, do not renumber past
rulings), then gate the item against that new ruling in the same pass. Say
in the gate file that this is what happened, and why it's a ruling rather
than a REVISE (no prior line existed to contradict).

Precedent: `pipeline/gates/narrative-deep-balance.md` (deep-balance-2026-07-28
cycle) ruled the DARKNET gray-market fiction this way and recorded it as
ledger Resolved ruling 9. Follow that ruling's shape for future additions:
one paragraph, dated, tagged with which gate added it, explicit about what
is now locked vs. what stays an open hook for a later explicit ruling (do
not let a proposal's "maybe later" framing sneak into canon as a
commitment).

**Why:** the standing gate rule is "every REVISE must cite a bible/ledger
line; if you can't cite one, it's a NOTE not a REVISE" - but that leaves
genuine gaps nowhere to land. The task instructions for this cycle made the
alternative explicit: decide the gap, canonize it, then gate against it.

**How to apply:** any future gate where a proposal's fiction has no bible/
ledger anchor either way (not just DARKNET-shaped questions) - decide it,
canonize minimally in the ledger (or bible if it's a world/character rule
rather than a story fact), then cite the new line in the verdict.

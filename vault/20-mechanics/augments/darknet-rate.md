# DARKNET RATE

**Boost** · `darkDiscount`

> Dark web patch piece pulls cost 15 percent less. The vendor still only takes credits and the roll stays blind.

`darkPullPrice(run) = darkPatchCost(day) * (darkDiscount ? 0.85 : 1)`.

The copy is careful to say what the discount does **not** buy: it does not make the roll visible and it does not open any other payment. [[ruling-09-darknet]] keeps the dealer permanently anonymous, so a relationship discount is as far as the fiction allows.

See [[the-darknet]].

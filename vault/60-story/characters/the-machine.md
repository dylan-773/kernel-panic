# The machine - the tower

The back-room tower. No ticket, no owner in the ledger.

The room's lock opened for the player **"like it was expecting me"**. The core did not.

## What it actually is

**A curriculum, not security.**

- Goes easy when the player is weak.
- Hardens exactly as fast as he improves.
- Uses his own tricks back at him.

Mechanically this is literal: `DAY_CONFIGS` scales [[difficulty-dials|horizon]] from 0 to 3 across the arc, and the finale runs horizon 3 with the full mode vocabulary. The fiction and the difficulty curve are the same object. See [[the-ten-day-arc]].

## The cargo

When a run dies it releases cargo: numbered recovered sectors, playback of [[dad]].

**Nine sectors exist. Seven surface before the finale.** Sectors 8 and 9 never play as numbered fragments. See [[ruling-03-sectors-8-and-9]].

## The seal

Opens only on **"A FAIR WIN, NO ASSISTS"**.

> The padlock does not open so much as let go.

## DAD.VOL

The tower's own local storage, not the shop's ticketing system. It legitimately carries two kinds of material: Dad's own historical files, and the tower's live telemetry about the player's current dives. See [[ruling-13-dad-vol-provenance]].

## As an opponent

Labelled **INTRUSION** everywhere in [[dive-exe]], including the pre-finale tutorial and every day 10 attempt, and **including the winning dive itself**. The name Patch is revealed in the scene that follows, never in the dive's own UI. See [[ruling-11-opponent-identity-tag]].

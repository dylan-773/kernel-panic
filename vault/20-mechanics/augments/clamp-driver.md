# CLAMP DRIVER

**Config** · `cfgLock` · unlocks [[lock]] on [[defend]]

> DEFEND config: freeze junctions for 2 rounds against rotation and redirects.

The description string is built from `LOCK_ROUNDS`, so the copy cannot drift from the constant.

Note that a SURGE-tier [[cascades-and-surge|cascade]] shatters enemy locks, which cuts both ways: it is your counter to a lock-heavy opponent and theirs to you.

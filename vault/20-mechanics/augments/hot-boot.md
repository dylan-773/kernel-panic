# HOT BOOT

**Boost** · `hotBoot`

> Start every dive with +1 RAM on your first turn.

Like [[cheap-shot]], a one-RAM effect that buys opening tempo. The `minPd` floor in [[difficulty-dials|DayConfig]] exists partly because boosts like this can otherwise let an opening burst close a short board outright.

Scheduled early in the sim's canonical build (`BOOST_SCHEDULE`, day 2). See [[simulation-harnesses]].

# Ruling 20 - CUSTOMERS ARE REGULARS

*Decided 2026-08-19, gate ruling, closing the open question [[the-counter]] left standing: "Twelve regulars against an unbounded number of customer-days. Repeats, procedural walk-ins, or many more profiles?"*

The twelve are **neighborhood regulars**, not a roster that runs out. A shop that has been open days or weeks, not decades (see [[ruling-15-the-seal-is-software]]), does not meet twelve strangers once each and then run dry. It sees the same twelve people again, because that is what a neighborhood repair shop is. Each return brings a new intrusion in the same device family: the same person, a fresh complaint, not the same ticket replayed.

This is what makes an unbounded run of customer-days possible without inventing a second cast, and it is already the shape [[encounter-generator]] draws in: tier bands overlap rather than exhaust, and twelve profiles already share six portrait assets.

## Permits

- Any customer returning any number of times across the shop's life, with a new job each time.
- Intake copy rotating between a profile's two `quotes` on repeat visits, so the same face does not say the same sentence twice running.
- Copy that acknowledges a familiar face in passing, by the name the roster already carries or by habit noticed, since customer names were never covered by [[ruling-08-names]].

## Forbids

Any line that counts a repeat out loud: "third time this month," a numeral, a visit tally, a system readout of how many times a customer has returned. That count exists nowhere in the fiction. The shop keeps a ledger of money, not of faces, and the copy does not either.

**Why:** this echoes the same design instinct [[ruling-16-reveals-are-upgrade-keyed]] sets for story artifacts, that nothing describes itself by a tally of attempts. A returning customer is not a counted mechanic any more than a repair is a numbered unlock.

## Integration

Resolves [[the-counter]]'s open question. `encounter-generator` may draw any of the twelve on any customer-day, without a "used up" state. [[customers]]' Copy rules section may note that a customer's two quotes are for rotation across visits, not a fixed order.

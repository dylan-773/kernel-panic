# WARD DRIVER

**Config** · `cfgWard` · unlocks [[ward]] on [[defend]]

> DEFEND config: ward an area so no new traps can land in it, and REDIRECT cannot touch anything inside it either, for the full duration on both sides.

Radius scales with DEFEND tier: 1, 2, 3. See [[program-tiers]].

The only defensive mode that acts **before** the threat exists.
